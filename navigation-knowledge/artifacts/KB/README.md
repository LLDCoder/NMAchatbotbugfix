# 页面知识

本目录位于 `navigation-knowledge/artifacts/KB/`，是 [现有页面目录](../page-catalog.json) 的附属知识。页面集合、身份和路由入口统一以该目录为准；这里按目录内页面补充数据、字段、统计、操作及限制说明，不独立新增页面或覆盖路由。相同页面知识可以用于不同问题，不按问题编号、测试用例或示例提问编写答案补丁。

页面说明和 page.json 中已有的身份、名称、路由属于目录引用或快照；更新时必须核对目录条目。冲突进入待核实清单，新增页面先维护现有目录，再添加本目录的补充说明。页面词表与检索索引仅从现有目录及绑定的补充说明生成。

## 文件约定

- pages/<portal>/<page>/page.md：供阅读的页面说明。
- 同目录 page.json：对应的结构化页面定义、字段语义和操作描述；按 [交换 Schema](knowledge-package.schema.json) 检查。
- 同目录 待核实项.json：尚需补充的页面信息。
- pending/：测试工具按页面归集的待核实信息；不保存会话问题、回答或数量。维护后合入相应页面说明。

待核实清单使用 [页面维护清单 Schema](page-maintenance.schema.json)。清单是维护入口，不是问答规则或可执行指令。test/run-generic-reader.mjs 使用通用导出工具归集页面缺口；原始问答与故障记录保留在 test/。

page.json 中 sources.reference 等源码引用仍以工作区根目录为基准；Markdown 链接按当前文件位置解析。目录迁移不改变页面业务定义、验证状态或知识记录版本。

源码和页面观测提供定义依据，当前账号与受信任执行策略决定权限。把文件放入本目录不会上传知识库，也不会自动启用其中描述的操作。

通用计算的字段对应关系见 [字段绑定说明](字段绑定说明.md) 与 [Schema](field-bindings.schema.json)。当前页面的 [字段绑定知识](<pages/admin/licensing-applications/My Application Tasks-实体标识与字段绑定.json>) 按页面描述实体和维度，包与记录均标记为 `active`；上传远端知识库并可被检索后即可参与流程，无需额外切换状态。核验信息及未明确事项保留在文件中。

页面视图、业务编号和列表到详情参数的说明见 [路由绑定说明](路由绑定说明.md) 与 [路由绑定 Schema](routing-bindings.schema.json)。流程不内置具体页面的标识映射；缺少映射时明确返回对应页面缺口。
